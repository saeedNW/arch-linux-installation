# Customization Guides

Welcome to the **Customization Guides** section. Here you will find guides for customising your desktop environment, theming your system, and making your Linux setup truly your own.

> **ℹ️ Note:** This section is organised by desktop environment / window manager. Each guide is self‑contained – you only need to follow the one that matches your setup.

## Which Guide Should I Follow?

- **If you use KDE Plasma** → follow the [KDE customization Guide](./kde/README.md). This is the most complete and up‑to‑date guide.
- **If you use GNOME** → the [GNOME customization Guide](./gnome/README.md) is available but **not actively maintained**. Some extensions may be deprecated or incompatible with newer GNOME versions. Proceed with caution.
- **If you use Hyprland** → the guide is in development. Check back later.

## Guide Structure

Each customization guide follows a similar structure:

1. **Introduction** – Overview of the desktop environment and customization philosophy.
2. **Prerequisites** – Required packages, tools, and dependencies.
3. **Theming** – Global themes, colour schemes, window decorations, and application styles.
4. **Icons & Cursors** – Icon packs, cursor themes, and how to apply them.
5. **Fonts** – Recommended fonts and configuration.
6. **Panel / Dock** – Customising the taskbar, dock, or top bar.
7. **Widgets / Extensions** – Useful add‑ons to enhance functionality.
8. **Wallpapers** – Where to find and how to set them.
9. **Terminal customization** – Shell prompts, colour schemes, and font settings (if not covered elsewhere).
10. **Troubleshooting** – Common issues and solutions.
